# 桌面界面

桌面界面（`blade_gui/`）用来查看结果，也可以替你拼好命令、启动命令行程序。它自己不做任何优化或 CFD 计算，所有动作都通过子进程调用 [优化流程](optimization.md) 和 [验证与诊断](validation.md) 里的命令行程序。

## 启动

```powershell
python -m pip install -r requirements-gui.txt   # 只需 PySide6
python -m blade_gui
```

在 Windows 上也可以双击 `run_gui.bat`，它会自动检查并安装 PySide6。

可选参数：

| 参数 | 作用 |
| --- | --- |
| `--config 配置.json` | 指定配置文件；不写时使用上次选择的配置 |
| `--data-dir 结果目录` | 只查看某个目录里的结果，例如从 CFD 主机拷回来的 `blade_al_runs` |

`--data-dir` 只改变界面上**显示**哪里的数据。真正启动运行时，结果仍然写到配置里的 `paths.output_dir`。界面会把这两个目录分别标出来。左下角的「设置数据目录…」与这个参数作用相同。

### 界面会记住什么

界面本身不内置任何路径。你选过的配置、数据目录、各表单里填过的值、窗口位置和大小、上次打开的页面，都会自动保存到本机的设置文件：

- Windows：`%APPDATA%\BladeShape\ActiveLearningGUI.ini`
- macOS / Linux：`~/.config/BladeShape/ActiveLearningGUI.ini`

删除这个文件即可恢复成初始空白状态。

## 界面布局

- **左侧栏**：六个页面的入口（`Ctrl+1` 到 `Ctrl+6`）、尝试/成功/Pareto/失败的计数、自动刷新开关（每 15 秒）、切换配置和数据目录。
- **顶栏**：当前配置文件（配置有错误时变红）、输出目录，以及"只读数据视图""任务运行中"等提示。
- `Ctrl+R` 立即刷新数据。

## 各页面

### 1. 总览

- 关键数字：总尝试数、成功数、失败数、Pareto 解数、最佳效率、最佳流量。
- **Pareto 前沿图**：横轴是流量，纵轴是效率。灰点是被支配的样本，阶梯线是工程容差前沿，圆环标出严格前沿。**单击任意点可跳到对应算例。**
- 最优值随时间的变化、样本来源分布、失败阶段分布。
- 代理模型诊断门的结论（见 [优化流程 · 第 7 节](optimization.md#7-检查代理模型准不准)）。

所有图表都支持：滚轮缩放、双击复位、鼠标悬停查看数值。

### 2. 数据分析

顶部可切换查看效率或流量。

- **变量分析**：各变量与目标的相关系数，以及散点图。成功样本少于 3 个时不显示。
- **代理预测质量**：预测值与真实值的对比图、预测误差和不确定度随迭代的变化。
- **主动学习进程**：每轮前沿扩张量、候选来源、局部搜索半径的变化。

这里的预测值都是 CFD 开始**之前**记下的，只用来评估模型，不会被当成真实结果。

### 3. 项目设置

用表单编辑 `blade_shape_config.json`：路径、运行参数、代理模型、Pareto 容差、几何约束、搜索空间、局部搜索、CFX 收敛标准。

- 带 ⓘ 的参数，鼠标悬停可以看到它的含义、推荐值和确定方法。右侧提示会随输入实时换算，例如把归一化距离换算成各变量对应的角度。「参数说明」按钮列出全部参数的说明，并注明改动会影响哪些续跑记录或方案签名。

- **设计变量表**：每个变量的下限、上限，是否参与搜索，以及不参与时的固定值。取消勾选某个变量，就是把它固定下来。表格的行顺序就是几何写入顺序，不要调整。
- 填错时（例如下限大于上限）会显示红色提示，并且不能保存。本机找不到外部程序只是黄色警告，不影响保存。
- 保存时会在 `config_backups/` 里留一份带时间戳的备份。路径类设置保存到 `blade_shape_local.ini`，不写进 JSON。
- 有未保存的修改时，自动刷新不会覆盖你正在编辑的内容。

### 4. 运行控制

可以启动五种动作，对应优化程序的五个子命令：

| 动作 | 用途 |
| --- | --- |
| 运行主动学习 | 真实 CFD 优化循环，可设置轮数、每轮点数、CFD 上限，并选择是否续跑 |
| 生成候选 | 生成单个候选并检查几何规则，不跑 CFD |
| 离线诊断 | 统计模型预测误差，不跑 CFD |
| 生成边界方案 | 从成功算例的下拉列表中选参考点，生成边界实验方案 |
| 运行边界阶段 | 选择方案文件和阶段（singles / pairs / extension）执行 |

- 运行前会显示完整的命令行，可以复制出来自己在终端里执行。
- 「本机环境检查」会列出 PowerShell、CFturbo、TurboGrid、CFX 在本机是否找得到。
- 启动真实 CFD 前会再确认一次。已有数据却没勾选续跑时，会给出明确警告。
- 日志实时滚动显示，错误显示为红色、警告为黄色、成功为绿色，可以保存日志。
- 「停止」会结束命令行进程，但 CFX 求解器可能仍在后台运行，需要自己确认。

在 macOS/Linux 上可以正常浏览界面，但真实 CFD 动作会因为找不到工程软件而失败，日志里会写明原因。

### 5. 算例浏览

- 左侧表格列出所有算例的编号、来源、状态、失败阶段、效率、流量，可以搜索和按成功/失败筛选。
- 右侧有四个标签页：概览、目录里的文件（双击用系统程序打开）、日志（显示末尾 800 行）、`candidate.json`。
- 如果 CSV 里记录的是另一台机器的路径，会提示"该算例目录在本机不存在"。这时用「设置数据目录…」指向本机的结果目录即可。

### 6. 验证

左侧是展向攻角验证的八个动作，每个都标明影响范围："只读后处理""写新文件"或"真实 CFD"。右侧「攻角诊断」显示这些动作输出的结果图表。

每个动作是做什么的、应该按什么顺序用，见 [验证与诊断](validation.md)。界面上有两个实用的小功能：

- 准备验证配置时，可以点「从优化算例填入」，程序会自动找到该算例已通过检查的 `.res` 和 `candidate.json`。
- 选择输出目录时只要选父目录，界面会自动在下面建一个带时间戳的新子目录，避免覆盖已有结果。

右侧的图表只是把命令行算好的结果画出来，界面自己不重新计算。退出码 2 表示质量或工况检查没通过，界面不会把它显示成成功。

运行控制页和验证页不能同时启动任务。

## 常见问题

| 现象 | 处理办法 |
| --- | --- |
| `No module named 'PySide6'` | 运行 `python -m pip install -r requirements-gui.txt` |
| 顶栏提示存在校验错误 | 到「项目设置」查看红色提示，改正后保存 |
| 运行页提示外部程序缺失 | 这台机器不是 CFD 主机，可以用 `--data-dir` 只看数据 |
| 算例详情提示目录不存在 | CSV 中是别的机器上的路径，用「设置数据目录…」指向本机结果目录 |
| 图表是空白的 | 对应的结果还没生成，例如还没有诊断记录时，预测对比图是空的 |
